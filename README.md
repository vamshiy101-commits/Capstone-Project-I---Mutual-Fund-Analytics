# 📊 Bluestock Mutual Fund Analytics

## 📌 Project Overview

Bluestock Mutual Fund Analytics is an end-to-end data analytics project designed to analyze Indian mutual fund data using Python, Pandas, SQL, SQLite, and advanced analytics.

The project implements a complete ETL pipeline covering:

- Data ingestion
- Data cleaning and validation
- Database loading
- Mutual fund performance analysis
- Risk analysis
- Investor transaction analysis
- NAV analysis
- AUM analysis
- Sharpe Ratio and Sortino Ratio analysis
- VaR and CVaR analysis
- Fund recommendation analysis
- Advanced analytics
- Reporting and presentation

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Build a complete ETL pipeline for mutual fund data.
2. Clean and validate multiple raw CSV datasets.
3. Store processed data in a SQLite database.
4. Analyze mutual fund performance and risk.
5. Compare mutual funds across different categories.
6. Analyze investor transactions and demographics.
7. Generate advanced risk and performance metrics.
8. Create reports and business insights.
9. Develop a reusable analytics pipeline.
